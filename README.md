# Desktop Voice-Based Assistant

A smart, hands-free desktop assistant that listens to your voice commands and performs tasks in real time. This project combines speech recognition, natural language processing, and automation to create an intuitive way to interact with your computer.

## **✨ Features**

* **Voice Command Recognition** – Understands spoken commands with high accuracy.
* **Application Control** – Open apps, websites, and system tools using only your voice.
* **System Automation** – Execute tasks like shutting down, searching files, or adjusting settings.
* **Web Search & Information Retrieval** – Ask questions and get instant spoken responses.
* **Custom Commands** – Easily add new trigger words and actions.
* **Lightweight Interface** – Simple GUI or tray-based assistant (depending on your setup).

# Technologies Used

* **Programming Language**: python
* **Speech Recognition:**  SpeechRecognition, Google-speech-text-recognition
* **Text-to-Speech:**  pyttsx3
* **Automation:**  OS libraries, custom scripts*

## **🚀 Getting Started**

### **1. Clone the repository**

```bash
git clone https://github.com/your-username/desktop-voice-assistant.git
cd desktop-voice-assistant
```

### **2. Install dependencies**

```bash
pip install -r requirements.txt

### **3. Run the assistant**

```bash
python final.py
```


## **🎤 Usage**

Speak a command such as:

* *"Open Chrome"*
* *"Search for news"*
* *"Play music"*
* *"What’s the time?"*
* *"tell me a joke"*

The assistant processes your voice input and performs the corresponding action automatically.
